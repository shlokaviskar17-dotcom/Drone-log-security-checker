# 🛸 Drone Log Security Checker

A lightweight Python tool designed to parse drone telemetry data in real-time to identify potential cyber-threats, signal disruptions, and system failures.

## 🎯 Features
* **GPS Spoofing Detection:** Identifies impossible positional jumps between consecutive telemetry records.
* **RF Jamming Alerts:** Triggers alerts when Signal Strength (RSSI) drops below safe operational thresholds.
* **Battery Safety Checks:** Flags critical battery levels that pose emergency landing risks.
